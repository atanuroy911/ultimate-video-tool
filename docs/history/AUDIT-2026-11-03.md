# Vision-to-product audit — 2026-11-03

This supersedes the **current-state claims** in the October audit and plan index, not their historical evidence. It distinguishes implemented code, a reachable UI, automated verification, and acceptance on real material. A plan checkbox or a registered module alone does not prove a finished feature.

## Vision used

The root handoff, ROADMAP, STATUS, the modules/audio-first/editor/reel/voice/Shorts/Social/client-server/packaging/setup plans and research index describe one product: a person supplies a script, recording or link; the Director chooses the appropriate capabilities; the person can understand and change every result; preview and export use the same editable representation. The owner's newer instructions supersede the old two-editor design and sentence-only visual timing. English is the current product priority. Remote GPU configuration remains 192.168.123.47; this audit did not change the owner's remote services.

## Measured inventory

`scripts/audit_capabilities.py` generates [the complete inventory](evidence/capability-inventory.json) from the actual registry and FastAPI app. This run found **165 modules, 135 in the autonomous toolbox, 40 visual components, 162 API routes and 18 page components**. Registry lint is clean. 164 modules can be opened as Studio forms; external posting uses the dedicated sharing flow. These counts describe interfaces, not successful real-world runs of every feature.

## Discrepancies repaired in this pass

1. **The agent could not see the tools it asked for.** meta.catalog/meta.describe results were cut to 600 characters, then the model request cut the result again at 800 and schemas at 6000. The full registry is now discoverable, schemas are complete, and a described capability enters the recent working set.
2. **The editor could do things the Director could not.** Exact edge/split/element edits now use shared functions in server/vt/editor_timing.py through Studio and timeline.edit_scene (CLI/MCP included). The autonomous toolbox includes reversible scene/layer editing.
3. **Valid graphics silently disappeared between fill and placement.** timeline.place previously supported text/media only. It now validates and inserts canonical components into editable scenes with exact ranges, updates all compositions, and rejects unsupported items without partial saves.
4. **Automatic layout overruled manual editing.** People-avoidance could remove a manually positioned visual. Edited/free visuals now bypass automatic removal and card exit decisions. Scene splits keep actions once, rather than duplicating the character scene. Action timing no longer changes selection indices.
5. **Content was silently capped.** Removed five-overlay and six-sound truncation in the Director contract/repair and scene merge paths. Readability remains guidance, not data loss.
6. **English UI and Director examples disagreed.** Director catalogue and Video Script prompt now share the library's English starter examples. They remain placeholders; the Director must replace them with grounded script content.
7. **UI state and controls were misleading.** Video settings toggles back to selection; dropdowns use opaque surfaces; word-anchor choices clear conflicting manual timing; fixed outer scene edges no longer accept values that do nothing; media start trims cannot extend before source footage.
8. **Existing choices were missing from creation.** New now exposes the backend's caption styles and optional reel closing line.
9. **Docs overstated or contradicted implementation.** Removed broken QA hyperlinks, marked missing historical reports honestly, replaced deleted editor paths, refreshed the measured facts and linked this ledger from current entry points.
10. **Visual QA exposed more navigation problems.** Caption editing now uses Details, keeping the preview visible instead of covering it with a modal. Typing also updates previews from the transcript panel, and Escape restores the saved text. Switching tool tabs resets their scroll position; whole-video settings no longer misleadingly says nothing is selected. The mobile position field keeps enough width to show precise seconds.
11. **Reused graphics kept the wrong time.** fill.graphic now applies the requested slot after copying the original visual, so an existing manual range cannot override the new placement. The regression covers this explicitly.
12. **A failed detector contradicted the English-first defaults.** Automatic language detection now falls back to English when the detector is unavailable. Explicit supported language choices are unchanged.
