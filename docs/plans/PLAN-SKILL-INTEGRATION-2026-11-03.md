# Reusable video skills and motion editing

The owner wants reusable production capabilities controlled through the app and Director, without generating new application code per video. Reference repositories are implementation references, not instructions to execute their agents.

1. Shared visual keyframes and motion presets for generated elements and added text/media; preview/export parity and preserved animation when splitting/trimming.
2. A reusable capability catalogue: motion graphics, kinetic text, characters/environments/props, diagrams, media, captions and quality checks. Expose matching controls to the Director.
3. Complete reusable story rendering and generation integration; verify character actions, environmental lettering and reused props in three formats.
4. Map useful external skill families to concrete capabilities. Never count a downloaded README as an integration.
5. Verify real frames/exports, backend and UI; finish Windows/Linux client/server packaging and release.

Acceptance: people can select Motion, choose a preset or save poses at chosen times, scrub immediately and export the same result. Splits preserve the absolute animation clock. The Director uses the same validated data. Invalid edits cannot partially save. Evidence distinguishes implementation, tested behavior and remaining acceptance work.
