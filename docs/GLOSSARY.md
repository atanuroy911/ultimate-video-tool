# Glossary: one name for each thing

Use these words in the screens, in server messages, in log lines and in the docs. A word in the last column may still appear where it means something else (a field name, a file name, code), never as the name a person reads for that thing.

| Use this | For | Replaces |
|---|---|---|
| Director | Who plans a video | AI model, AI provider, Ollama model, planner, "the editor" when it means the AI |
| Editor | The timeline page only | |
| Quality check | The score and the things to look at | Viewer test, Retention check, Craft score, Judges, Editor notes |
| Things to look at | What a check found | violations, risky moments, "problems" in screen text |
| Style | How a video is drawn | Kind of video, Visual style, Drawing style |
| Purpose | What a video is for (the director's hint on the New page) | Kind of video (it was a second meaning of the same words) |
| Look | Colours and type | Theme, Design Studio, the nav item "Styles" |
| Direct again | Redoing the plan | Redo with AI model |
| Export / Download | Make the file / save it | Render, Render video |
| Server | The computer doing the work | "Video Tool server 1", engine server |
| Helper | The small program on the person's computer that keeps Claude and Codex ready for the server | companion, micro server |
| Your videos | The list | Projects |

Where the old words still live, and may: code and file names (`planner`, `theme.json`, `/api/projects`, `"viewer test"` as the author of a note in an existing chat file), the word "render" for what the program does inside (`render_silent`) and in developer docs, and "theme" in the schema and API.
