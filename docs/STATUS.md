## Known gaps (honest list)

- **Video quality is the open question.** The first real Claude-directed video shows empty screens, text printed over text and unreadable colours ([matrix-findings.md](dev/matrix-findings.md)). The work to improve it is `docs/plans/PLAN-PERFECT.MD`; the matrix (`scripts/lab/local_matrix.py`) measures it.
- **Only one matrix row has been made so far**; the rest of the 20 (other styles, formats, Bangla, Banglish) are running or pending.
- **Browser (end-to-end) suites** are not in CI: the last full run (2026-10-26) had 11 of 24 failing. Triage is step W3.5 of `docs/plans/PLAN-WORKBENCH.MD`.
- **Not accepted yet** (from the 2026-11-03 audit): a clean-machine install on Windows and Linux, real social-account posting, measured director quality, classic plan review.
- **The editor layout** is being redesigned (docked panes, an assistant pane with Claude Code inside): `docs/plans/PLAN-WORKBENCH.MD`, phases W6 to W15.
- **Known intermittent crash**: the server process died once in the "listening for sounds" step (a native GPU library error), and the server window does not restart a crashed server (F1 in matrix-findings.md).
