# Is everything wired to the UI? (2026-11-07, Claude)

The owner asked whether everything is wired properly to the UI. This file records what was checked, how, what was broken and what was fixed. The rule it checks against is "the UI wraps everything": a person never runs a command after install.

## How it was checked
1. **Routes, measured.** A script loaded the real FastAPI app (`vt.server.app.app`) and listed all 167 `/api`, `/ws`, `/media` and `/mcp` routes. It then collected every `/api/...` path that the Studio (`client/studio/src`), the desktop app (`client/desktop`), the server's own pages (`server/vt/server/*.js|html`) and the server window (`server/desktop`) call. Template parts such as `${id}` became wildcards, and each path was matched against the routes.
2. **Desktop bridge.** Every `ipcRenderer.invoke/send` in both preloads was compared with every `ipcMain.handle/on` in `main.js`, and every `vtDesktop.*` the Studio uses was compared with what the preloads expose.
3. **Settings with no control.** For the New page, every `useState` setter was checked for a control that can reach it.

Server routes no app screen calls, and why that is acceptable:
- `/mcp`, `/mcp/director`, `/ws`, `/media/...`, `/api/docs`, `/api/openapi.json`: protocols and assets, not buttons. Audio cut, mute, gain, split, restore, undo and redo are called through a built-up path in `useReview.ts`.
- `/api/house-rules`, `/api/scene-types`, `/api/icons/{name}`, `/api/styles[/{slug}]`: lookups for agents (MCP, CLI). The house rules reach the person inside the prompts shown in Details, AI conversations.
- `/api/mcp/connect-claude-desktop` and `/api/mcp/connect-codex`: superseded by `/api/assistants/{id}/connect` (Settings, AI assistants) and kept for `tests/test_api.py`. They write config on the *server* computer, which is wrong for a remote server. **Candidates for removal.**
- `PUT /api/projects/{pid}/video-kind`: superseded by Direct again (style choice). Used by `tests/test_modes.py`.
- `GET /api/projects/{pid}/qa/frame/{name}`: the frame check lists problems in words but does not show the frame. **A small gap:** showing the frame would help.
- `POST /api/projects/{pid}/scenes/undo`: the editor's Undo keeps its own history of the person's edits. AI tools (MCP and modules) write the server's one-step backup `scenes.prev.json`. **Gap:** a change Claude made over MCP cannot be undone from the app. "Undo the director's last change" in the AI panel would close it.
