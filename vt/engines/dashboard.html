Connect another device

  1. Open Video Tool on your other device.
  2. In Settings, open Computers & setup and choose another Video Tool computer.
  3. Enter this computer’s network address and the one-use code below.

Use the network address printed when this server started. “localhost” only works on this computer.

Creating a new code replaces the previous unused code. Devices already connected keep working.
