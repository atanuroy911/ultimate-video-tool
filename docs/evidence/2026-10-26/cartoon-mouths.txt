Cartoon lip-sync rig: before and after the regex fix (2026-10-26)

Bug: renderer/runtime/vt-stick.js line 190 searched each mouth drawing's class with /mouth-([A-HX])<BACKSPACE>/ instead of /mouth-([A-HX])\b/.
A backspace character never occurs in a class name, so no mouth shape was ever found, `o.mouths` was never set, and the code that shows one
mouth shape at a time (lip-sync with the voice) never ran.

Method: the composition of the real project projects/2026-10-24-bill-and-ted-were-playing-ball-5 (9:16) was COPIED to a scratch folder twice;
one copy kept the project's own runtime (old), the other got the fixed renderer/runtime/vt-stick.js (new). Each was opened in headless Chrome
at 540x960, the paused GSAP timeline was moved to a time, and the .mouth-group elements that are displayed with opacity > 0.5 were counted.

                                  old runtime        fixed runtime
  mouth groups in the page        324                324        (36 characters x 9 mouth shapes A-H, X)
  visible at t = 0.4 s            324                (36 at t = 2.0 s)
  visible at t = 1.0, 2.0, 3.5, 5.0 s   324 each     36 at t = 2.0 s: exactly one shape per character

With the old runtime every character drew all nine mouth shapes on top of each other; the page was so heavy that a screenshot did not finish in
140 s. With the fix one mouth shape per character is visible.

The same defect (backspace instead of \b) was found in vt/script/score.py lines 55-56 (the "X means Y" and "first, then, next" cue patterns never
matched English text). Both are fixed. tests/test_no_control_characters.py now fails on any control character in the source files.
