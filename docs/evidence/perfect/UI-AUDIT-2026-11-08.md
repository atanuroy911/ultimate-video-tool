# UI friendliness audit: server, helper, install and setup (2026-11-08, Claude)

The owner said the server and helper screens "do not look professional or user friendly" (example: the chip "kept free for you"), and asked for a full audit of the helper, the server, installation and the setup menus, judged by Apple's design principles, then fixed.

**Principles used:** clarity (plain words, one name per thing, no internals), deference (the person's task first, quiet chrome, nothing repeated), depth (rare things behind one "Advanced"), consistency (one look in light and dark across every window), and honest state (say what is true and what to do next).

**How:** every surface was opened and screenshotted (light, dark, 1280 and 400 wide), and every string behind it was read: the server app window (`server/desktop/server-manager.html`, rendered through `preview-manager.js`), its tray menu, its first-start steps, the server's own pages (`/` and `/manage`), the Studio's Server page, setup wizard, Settings > Directors & assistants and the helper card, the client's welcome screen (`client/desktop/connect.html`), its menus and dialogs, and both uninstallers.

## Second pass ("fix the rest", same day)
- **One icon family.** The app's mark (orange square, white play, yellow bar) was already the favicon, the phone icons and the client icon; the Studio sidebar drew a purple-pink one and the server was blue. The sidebar now draws the app icon itself, and the server icon is the same image recoloured (graphite square, orange play, same bar), made by `scripts/make_app_icons.py` from `client/desktop/build/icon.png`.
- **The real windows**: the installed server window was captured (`PrintWindow`) after installing on E:. It showed the new look in Windows dark mode, the new icon and the real network addresses, and one real bug: **"Start when I sign in" showed off although the entry was in Windows' startup list** (Electron's check compares a quoted path). Both apps now read the Run entry themselves (`reg query`), checked against the real registry: server and helper both read as on, a missing entry reads as off.
- **Preferences**: the Look list showed 64 per-video looks ("auto-…", many twice) before the real ones; it now lists each named look once (a video's own look shows only when it is the saved default).
- **Voice & speech**: "The recording stays on this computer" was untrue (it is kept on the server); the speech-reader table said "bn-medium · Bangla fine-tune (converted locally to CTranslate2, ~1.5 GB)"; it now says Bangla / Most accurate / Balanced / Fastest with the size, and "Saved on the server".
- **Picture libraries**: "they stay on this computer" (untrue) and a long paragraph; now "Keys are kept on your server and sent only to that site", "Not set up".
- **Help & checks**: the 4-second check now says what it is doing.
