# H1 and H3 - the real app, and connecting from nothing

- **H1:** `scripts/build_client_windows.sh` built the installer (82 MB, icon embedded by rcedit); installed with `/S` while the app was closed; opened with `ELECTRON_RUN_AS_NODE` removed. The main process was still alive after 15 s, the window is titled "Ultimate Video Tool Studio", and the screenshot (`H1-real-app.png`) shows Your videos with the new server's video, the server's GPU, processor and memory in the sidebar and "Director: Local AI".
- **H3:** the settings folder (`%APPDATA%\Video Tool`) was moved aside so the app started with nothing, then `Ultimate Video Tool.exe --server http://192.168.123.47:8790`. It connected with no code and no question; `desktop.log` says `Command line: server http://192.168.123.47:8790` and `Client UI is local; processing server: http://192.168.123.47:8790`; it wrote `connection.json` with that address. Screenshot `H3-from-nothing.png`. The old settings folder was put back afterwards. (The app chooses its own data folder: `--user-data-dir` is ignored.)

Found and fixed on the way: the first run registers the helper to start with the computer (by design, M7), but under the name `electron.app.Electron`, which Windows Startup apps would list as "Electron". `client/desktop/main.js` now passes `name: 'Ultimate Video Tool Helper'`; after the rebuild and reinstall the entry reads `Ultimate Video Tool Helper = ...\Ultimate Video Tool.exe --helper`.
