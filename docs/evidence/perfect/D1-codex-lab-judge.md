# D1 lab judge implementation — Done by codex

2026-11-07. `vt_lab.py judge <project>` checks the newest finished MP4 and the saved composition for its shape. `--file` selects an export by filename. `--data` uses a local data folder instead of the lab server. The command exits 1 if a check fails and prints PASS or FAIL for every check it can evaluate.

The command compares the recorded director with the conversation log and checks for a fallback notice. It uses the same software browser probe as `frame_facts` at 0 s and the midpoint of every composition scene. In acceptance mode the probe measures combined rectangular face coverage before rounding, finds bounds that extend more than one CSS pixel outside the frame, and distinguishes a visible subject from a caption on an empty set. The default director probe still returns its original fact strings.

The judge also runs the existing craft, retention and video judges, measures the required −16 to −12 LUFS range, and checks `blackdetect=d=0.1:pix_th=0.12` on the existing MP4. Missing samples and failed video decoding yield a failure. The read-only lab path leaves the saved plan, composition, export and judge sidecar alone. The Studio judge keeps saving its sidecar as before.

- `tests/test_lab_judge.py` passed all eight cases. A complete passing fixture exits 0. The bad fixture fails all ten checks and exits 1. The test also checks missing frame or audio measurements, corrupt decode, unsafe export paths and the Studio sidecar behavior.
- `node e2e/frame_measurements.mjs` passed eight checks in software Chrome. It includes combined face coverage of 12% from two 8% overlays that share 4%, a single 10.25% overlap, small overflow, and a caption-only opening.

It passed the frame, craft, retention and black flash checks. It measured −26.1 LUFS and failed the loudness and picture-change judges, giving exit 1. Project files and their hashes were identical before and after the command.
