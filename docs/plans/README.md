# Plan implementation audit

Checked against the source and focused tests on 2026-10-26, with the director-module row refreshed on 2026-10-27. The detailed plans describe the intended product; this page records what has actually been verified.

| Plan | Implemented in source | Automated verification | Remaining acceptance work |
|---|---|---|---|
| [Core product](../../plan.md) | Pipeline, editor, AI direction, Shorts and Social surfaces exist. | The core plan's older measurements are historical and were not rerun in this audit. | Its listed M2, cold-open, talking-head polish, taste, and product gates remain open. |
| [Shorts](PLAN-SHORTS.MD) | Detector and prompts (`vt/shorts`), sentence snapping, child project slicing, API routes, and Studio page with direct video upload, source video review, swipe/arrow navigation, caption and speaker options, and batch export. | [Live QA](../qa/shorts-ui-2026-10-26.md): 7 backend tests, browser control smoke test, accepted video upload form, and one real candidate-to-Short render with A-roll in 4/4 scenes. | Run candidate detection and batch rendering on three long videos; get human agreement on at least 3 of the top 5 picks; inspect sentence boundaries and face framing. | [Social](PLAN-SOCIAL.MD) | SQLite queue and worker (`vt/social/core.py`), Meta/Instagram/YouTube/TikTok upload branches, account and group API, Result dispatch, Social hub, logs and retry. | `tests/test_social_flow.py` covers mock dispatch, isolation of failed tasks, retry, path rejection and an Instagram upload with mocked HTTP. | Connect real accounts and confirm one live post and stored permalink per platform. Other live platform flows and rate limits lack live verification. The plan names separate adapter modules; current implementation keeps them in `core.py`. The plan's account connection flow is token entry/Meta token exchange, not a complete OAuth login UI for every platform. |

The live director UI and plan review are later phases. |
| [Audio-first direction](PLAN-AUDIO-FIRST-DIRECTOR.MD) | Decided 2026-10-26 (owner). First step is the 20-clip direction set with human edits. |
